# 文件系统维护

本文汇总文件系统实现需要检查的行为。当前适配器、会话与索引路径见 [架构说明](ARCHITECTURE.md)。

ReFS 使用本地纯 Rust `refs-reader`，正式构建不需要 librefs DLL；旧 DLL 仅供显式对照。候选调查、移植来源、公开镜像及验证范围见 [ReFS Rust 后端与替换验证](REFS.md)。普通文件和快照流共用 extent 映射执行范围读取，未写入区间返回零，链接读取返回 UTF-8 目标文本。

## 时间戳

保留源格式的时间角色、精度和时区依据。无偏移的本地时间不能直接标为 UTC；FAT 本地时间、exFAT UTC offset、NTFS FILETIME 和 APFS 纳秒值需要分别处理。NTFS 的标准信息和文件名属性时间应独立保留。

测试覆盖零值、未设置值、合法边界、时区偏移和精度转换。格式化字符串用于展示，排序与投影应使用数值时间；时间线的当前投影规则另见架构说明。

## 目录与删除项

遇到删除或损坏目录项时，不能提前结束后续有效项的枚举。区分现存目录项、原生删除项、结构残留与雕刻候选；删除项的目录身份与数据块可恢复性应分别验证。

恢复读取按文件逻辑长度裁剪，避免把簇尾空间拼入正文。重用记录、同名候选、多父目录和符号链接需要显式处理，不猜测缺失父链。独立文件系统孤儿扫描尚未接入。

## 多卷与派生视图

APFS 容器内卷、Btrfs 子卷、LVM 逻辑卷和 Docker 合并卷各自保留卷身份，不能只取第一个卷或在缓存键中混用身份。命名流、扩展属性与文件系统元数据节点应具有明确的读取路径和来源范围。

加密视图和 VSS 会话镜像依赖源镜像，卸载时需释放其会话、索引、预览、插件证据句柄和挂载。

## 读取与压缩

支持的压缩结构应解码为文件逻辑字节，未支持的编码应明确报错。`Volume::read_range`、完整读取和流式读取必须返回一致字节；不能随机寻址的适配器可使用流式回退，但需考虑 O(offset) 的成本。

当前 NTFS、Ext4 与连续镜像范围可直接寻址，Dokan 缓存未命中复用该范围读取路径。适配器回归之外，还需通过真实挂载检查 OS 读取、只读保护及卸载，在 Windows 桌面中验证挂载后的文件哈希、随机读取、只读保护和卸载清理。

NTFS 的普通 `$DATA` 和命名流通过同一逻辑读者处理 LZNT1：按压缩单元拼接已分配簇，
区分未压缩单元、纯稀疏单元与压缩数据后的稀疏补齐，跨 `$ATTRIBUTE_LIST` 连接首段和后续段。
每个读者只缓存一个解压单元（最多 1 MiB），范围读取从所需单元开始；未初始化尾部按 NTFS 规则返回零，
损坏块、非法回溯和短解压均报错。MIME、魔数和熵采样使用解压后的逻辑字节，EFS 仍明确拒绝读取。

可用 `just run-example probe_ntfs_stream <镜像路径> <分区ID> <MFT记录号> [独立对照文件]`
核对完整、流式与范围读取。探针限制文件为 16 MiB；对照文件应由独立实现生成。
提交的 LZNT1 固定样本由 Windows `RtlCompressBuffer` 对合成字节生成，不含检材内容。

文件大小、extent / run / cluster 范围和乘加运算均需校验。短读不能冒充完整文件；整盘哈希、RAW 导出与解密导出必须检查 `offset == total`。

## 验证矩阵

| 场景 | 检查 |
| --- | --- |
| 完整、截断及损坏镜像 | 分区边界、错误上下文、坏区报告与探测兜底 |
| 多卷与多镜像 | 卷键、节点身份、缓存隔离与卸载清理 |
| 时间与编码 | 数值、角色、偏移、精度与非 ASCII 名称 |
| 删除、稀疏与压缩文件 | 逻辑长度、字节校验值、状态与来源 |
| 全量、流式与范围读取 | 不同块边界下逐字节一致 |
| 取消与资源上限 | 输出清理、终态与资源释放 |

优先使用最小合成样本；公开样本记录来源、许可与哈希。第三方代码和数据声明保存在 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 及对应 vendor 目录。


## NTFS 与 libfsntfs 对照

当前 NTFS 正文统一通过 `LogicalStream`：普通和 LZNT1 走 `DataStream`，WOF file provider
走 `WofStream`。WOF 支持 XPRESS-Huffman 4K/8K/16K 和 LZX 32K，按需读取 offset table、
缓存单个块；默认/ADS 的完整、流式、范围与采样保持相同字节契约。
同目录硬链接按原始名称分别投影；符号链接与 junction 保留检材目标，不自动跟随宿主路径。
元数据 API 分开保留 SI/FN 时间和原始 FILETIME，可读取属性映射、安全描述符与独立导出的 MFT。
完整公开 API 对照、验证来源及未覆盖场景见 [NTFS 能力对照](NTFS.md)。
