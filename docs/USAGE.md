# 使用指南

## 案件与证据

1. 启动桌面程序，在案件管理中创建案件或打开已有案件目录。
2. 使用「添加证据」选择磁盘镜像、逻辑证据、文件夹或物理磁盘。分段镜像应选择首段，并保留其余分段。
3. 在镜像信息页查看逻辑大小、格式、分区、采集信息和平台识别结果。
4. 需要解锁的卷先输入对应凭据；RAID 成员盘可从识别与 RAID 页面重组。

加入案件后的自动识别，以及镜像信息页手动发起的重新识别，都会显示在「任务中心」的任务列表中。可查看平台与检材类型结论、失败原因或取消状态，并从任务打开镜像信息页；卸载镜像会取消其识别任务。

案件目录保存案件台账 `case.db`（案件信息、证据登记、任务、标签与操作审计）以及每个证据各自的目录（卷快照、文件索引、哈希、分析结果、时间线与搜索记录）。证据原件应保持可访问；案件登记不等于复制原件。移动案件或证据后，应检查路径与加载结果。早期版本的案件不能打开，需要新建案件，详见 [架构说明](ARCHITECTURE.md)。

起始页显示最近 8 个案件，点击可恢复证据页；清空记录需确认，只移除本机历史，不删除案件。镜像属性与校验操作见 [IMAGE_INFO.md](IMAGE_INFO.md)。

添加 iOS 本地备份时选择包含 `Manifest.plist` 与 `Manifest.db` 的单个备份文件夹。加密备份从镜像信息页解锁为只读子会话；目录选择、异常检查和适用范围见 [iOS 备份](IOS_BACKUPS.md)。

## 浏览与预览

软件版本与构建时间可在「设置中心 → 关于」查看；「日志」显示当前会话输出，可搜索、按级别筛选、复制全部或清空。主题仅在「设置中心 → 界面」切换。主窗口不再显示全局底部状态栏。

进入文件列表后按卷和目录浏览，或使用全显与列筛选定位文件。删除项、未分配空间和文件系统元数据节点依卷类型展示；可浏览的删除项不保证其内容仍完整。

选中文件可查看属性、文本、Hex 或原类型预览。数据库和可执行文件提供结构化视图，部分文档由离线预览资源渲染。预览受格式与大小限制，超限时可导出后使用合适的查看器。

文件预览可拖出为独立窗口，后续文件选择会在同一个窗口中更新；拆分和停靠保留当前标签、搜索、编码、Hex 页码及正文阅读位置。切换文件保留视图选择；窄工作区内预览浮在表格上方，可关闭后继续浏览完整列表。LevelDB 与 MMKV 目前使用文本或 Hex 查看，不提供专用键值视图。

点击表头列名可以排序，也可用 Tab 聚焦列名后按 Enter 或空格操作。大小与时间范围筛选须填入有效值，范围颠倒时会提示错误并保留原结果；修正后重新点击「激活」。文件属性中的「加密类型：未检测」表示没有检测依据，不能据此认定文件未加密。

标签可用于整理文件；分析结果中的「定位源文件」会导航到实际证据来源。BCP 数据集的索引、字段和分页说明见 [BCP.md](BCP.md)。

## 校验与导出

镜像信息页可计算源盘哈希；文件列表提供单文件哈希、文件及目录导出，镜像可导出为 RAW 或解密视图。选择输出目录后查看任务进度与最终结果。

整盘读取必须覆盖完整逻辑长度。读取错误、坏区或合成零字节会影响结果解释，应同时保存任务返回的故障报告。导出名称会适配主机文件系统，不覆盖已有文件；原始路径和来源信息仍应以案件记录为准。

卷影副本可按需打开为只读会话镜像。它和加密卷的会话视图依赖源证据，关闭或卸载源镜像后需重新打开。

## 搜索、时间线与雕刻

- 全局搜索按指定范围执行关键词或正则匹配，支持多种编码、任务历史、分页命中与 CSV 导出。查看命中时结合源文件和字节偏移核验。
- 时间线从文件索引与插件事件投影生成。源数据变更后按页面状态创建或更新投影，再使用时间范围和事件类型筛选。
- 文件雕刻在选定字节区域的 512 字节块边界检查签名，再解析文件结构。扫描支持暂停、继续与取消，可恢复所选或全部结果，并生成 SHA-256 与 DFXML。扫描记录保存在当前进程会话中，重启后不会保留。

雕刻存在块对齐、碎片化和格式覆盖限制，不能把未命中解释为文件不存在。

雕刻结果按页读取，应用文件名、类型或偏移筛选后会继续读取剩余结果；读取期间显示进度，全部读取完成后才给出完整匹配数量。「清除筛选」停止继续补页，已读取结果保留。结果表使用虚拟滚动；全选仍勾选全部已加载且符合筛选的结果，不限于屏幕内的行。恢复全部始终作用于当前扫描的全部结果。

搜索和雕刻的结果、历史读取失败时，页面显示原因与「重试」，不会将读取失败解释为没有结果。新建搜索的命中上限须为正整数，错误显示在对应字段旁。

时间线热力图与趋势图各占一个 Tab 停靠点。热力图使用上下键移动一天、左右键移动一周；趋势图使用方向键移动一个时间桶。Home / End 跳到首项或末项，Enter / 空格选择并下钻。窄面板可横向滚动图表，键盘移动会自动滚动到对应项；事件类型弹窗打开时移入焦点，关闭后返回入口。

## 插件分析

「任务中心」跟随顶部当前检材标签。在「快速分析」中按平台与检材类型查看可用插件，按分类勾选或全选插件后提交；每个插件会运行当前平台下适用的全部检材分析功能，不提供子项勾选。插件格子显示最近任务状态，需要目标文件的功能从文件列表右键「插件分析任务…」提交。

任务列表展示进度、错误与控制操作；收起面板或切换页面后，后台任务继续运行。完成后在「分析结果」中查看记录、详情和源文件，或导出 CSV。

插件通过 LPP 动态库提供能力。已发现插件会被视为可信代码，默认使用独立进程；安装前应了解插件来源。安装与接口见 [PLUGIN_PROTOCOL.md](PLUGIN_PROTOCOL.md)，仓库仅内置 [Linux 基本信息插件](LINUXINFO.md)。

## 命令行

`just run-cli` 启动开发版独立终端，支持会话内打开证据、目录浏览、分析与 JSONL 调用。命令行操作、结果格式和测试方法见 [CLI.md](CLI.md)。

Windows 桌面只读挂载需要可运行的 Dokany 驱动，可从镜像信息页挂载卷。
